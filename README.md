# אחמד סרסור · מהנדס דאטה ומפתח מערכות BI

אתר תדמית אישי, עמוד יחיד, עברית ואנגלית (RTL/LTR), ללא תלויות בנייה.

- **Live:** https://ahmad-sarsor.github.io/portfolio/
- **Branch:** `gh-pages` (GitHub Pages מוגש ממנה)

## מבנה

```
index.html          העמוד כולו: HTML, CSS ו-JS מוטמעים
assets/logos/       לוגואים של כלים ולקוחות (SVG/PNG)
.nojekyll           מבטל עיבוד Jekyll ב-Pages
```

## פיתוח מקומי

אין תהליך בנייה. פותחים את `index.html` בדפדפן, או:

```bash
python -m http.server 8000
```
